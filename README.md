# 🌊 Dahilia Creations – Web Application Prototype

A high‑fidelity **web application prototype** developed using **ASP.NET Core MVC**. This project was created for **my first client project for a friend based in the UAE**, where I independently designed and developed the prototype within **one week**.

The platform is **still under active development**, with continuous improvements, refactoring, and feature enhancements being added as the project evolves.

The project started as a **hand‑drawn concept on paper**, which was then transformed into a functional digital prototype. The goal was to design a **modern, immersive, and scalable web experience** while maintaining clean backend architecture and intuitive UI/UX design.

---

# 🚀 Project Overview

This platform was designed to simulate a **real‑world business system** where administrators can manage products while customers can browse and place orders.

The prototype focuses on:

• Practical **ASP.NET Core MVC architecture**
• Clean **UI/UX design with consistent visual language**
• **Role‑based access control** for system users
• Functional **product browsing and ordering workflow**
• Rapid development using **AI‑assisted workflows**

The application demonstrates how a simple concept can be transformed into a **working product prototype in a short development cycle**.

---

# ✨ Key Features

## 🔐 Authentication System

A full authentication flow designed to simulate real application usage.

Includes:

* Login
* Registration
* Forgot Password

The authentication screens use **cinematic video‑based backgrounds** to create an immersive first impression while maintaining usability.

---

## 👨‍💼 Admin Management

Admins have control over the core system data.

Admin capabilities include:

* Add new fish listings
* Edit product details
* Manage available listings

This enables a structured system where **content can be managed without modifying code**.

---

## 🐟 Product Browsing

Users can explore available fish listings through a clean and simple interface.

Features include:

* Browse listings
* View product details
* Explore available inventory

The focus was to ensure **clarity and ease of navigation for end users**.

---

## 🛒 Ordering Flow

Users can place orders directly from the application.

The goal of this module was to simulate a **basic e‑commerce interaction flow** where customers can move from browsing to placing orders smoothly.

# 🧠 Development Approach

The project followed a **rapid prototype development approach**.

1. The concept started as a **hand‑drawn wireframe on paper**.
2. The structure and user journey were redesigned digitally.
3. UI and backend logic were implemented simultaneously.
4. AI‑assisted development tools were used to accelerate workflow.

This approach helped convert an early idea into a **working functional prototype within one week**.

# 🎨 Design Philosophy

The design was built around three main principles:

**Consistency**
All views maintain a unified design language to ensure the user experience feels cohesive across the entire application.

**Immersion**
Cinematic authentication screens help create a strong visual entry point for the application.

**Clarity**
Interfaces were designed to remain simple and intuitive, ensuring users can easily navigate through the system.
